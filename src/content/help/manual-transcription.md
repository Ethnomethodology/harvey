For high-precision work or difficult audio, you can transcribe manually using Harvey's specialized tools.

*   **Smart Initialization:** When setting up a manual transcript, the **Number of Segments** and **Duration** are bidirectionally linked. Adjusting one automatically calculates the other based on the total media length.
*   **Segmentation:** Create custom time-stamped segments manually. The system ensures segments are perfectly contiguous.
*   **Direct Entry:** Type directly into the segments while controlling playback with global keyboard shortcuts.
*   **Flexibility:** Combine manual entry with automatic results by editing existing segments at any time.
