### Translation

Harvey supports local machine translation using the **Helsinki-NLP** and **NLLB** (No Language Left Behind) models. Translation is optimized using **CTranslate2** for high performance on standard CPUs.

#### Core Features
*   **Privacy:** All translations happen locally. Your sensitive data is never sent to external servers.
*   **Transcript Translation:** Translate an entire transcript while maintaining the original timestamps and speaker labels.
*   **Side-by-Side View:** View the original and translated versions together in the editor for easy comparison.
*   **Document Translation:** Quickly translate your research notes and other documents in the Data tab.

> **Requirement:** You must download the specific translation models for your language pair in the **Configure** screen before using this feature.
