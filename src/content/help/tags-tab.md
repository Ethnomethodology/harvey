The Tags tab provides a birds-eye view of your qualitative coding schema.

*   **All Tags:** View a flat or grouped list of every tag defined in the project.
*   **Frequency:** See how many times each tag has been applied across all documents and transcripts.
*   **Management:** Add, rename, or delete tags. Renaming a tag updates it globally across the project.
