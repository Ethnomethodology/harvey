### Transcription Engine

Manage the **Whisper.cpp** models used for local transcription.

*   **Available Models:** Download various model sizes (Tiny, Base, Small, Medium, Large). Larger models are more accurate but require more RAM and processing power.
*   **Hardware Acceleration:** On macOS (Silicon), Harvey uses Core ML for optimal performance. Windows users can leverage specialized builds for acceleration.
