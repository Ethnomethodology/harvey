# Keyboard Shortcuts

| Action | Windows/Linux | macOS |
| :--- | :--- | :--- |
| Play/Pause | `Ctrl + Space` | `Cmd + Space` |
| Rewind 5s | `Ctrl + Left` | `Cmd + Left` |
| Forward 5s | `Ctrl + Right` | `Cmd + Right` |
| Save | `Ctrl + S` | `Cmd + S` |

> Tip: You can customize these in settings.
