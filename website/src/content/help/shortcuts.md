Master these platform-aware shortcuts to significantly speed up your workflow.

| Shortcut | Action |
| :--- | :--- |
| `Ctrl/Cmd + E` | Toggle Edit Mode |
| `Ctrl/Cmd + S` | Save Transcript |
| `F8` | Play / Pause Media |
| `F7 / F9` | Rewind / Forward 5s |
| `Ctrl/Cmd + ↑ / ↓` | Previous / Next Segment |
