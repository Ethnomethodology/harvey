Download the latest version of Harvey for your operating system.

### Windows
*   **Installer (.msi):** The easiest way to install. [Download Latest](https://github.com/Ethnomethodology/harvey/releases/latest)
*   **Requirements:** Windows 10 or 11 (64-bit).

### macOS
*   **Apple Silicon (M1/M2/M3):** Optimized for performance. [Download Latest](https://github.com/Ethnomethodology/harvey/releases/latest)
*   **Intel Macs:** Standard version. [Download Latest](https://github.com/Ethnomethodology/harvey/releases/latest)
*   **Installation:** Drag the `.app` file to your Applications folder.

### Linux / Source
Currently, we support Linux via building from source.
1.  Clone the repository: `git clone https://github.com/Ethnomethodology/harvey.git`
2.  Install dependencies: `npm install`
3.  Run the app: `npm run tauri dev`
