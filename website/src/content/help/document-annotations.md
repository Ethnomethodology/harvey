Annotate text-based documents using the integrated rich text editor.

*   **In-line Comments:** Add notes to specific text selections.
*   **Text Highlights:** Use color-coded highlights to categorize different themes.
*   **Cross-Referencing:** Create links between different parts of a document or even between different files.
