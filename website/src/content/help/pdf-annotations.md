PDF documents can be visually annotated using standard tools.

*   **Visual Highlighting:** Select and highlight text directly on the PDF page.
*   **Sticky Notes:** Place comments anywhere on the document layout.
*   **Integration:** All PDF highlights are searchable and appear in the project-wide highlights panel.
