### Advanced Settings

Tools for troubleshooting and advanced system management.

*   **Developer Logs:** View internal application logs to diagnose issues.
*   **Python Management:** Reset or re-initialize the internal Python virtual environment if libraries become corrupted.
*   **Cache Management:** Clear temporary files and downloaded model caches.
